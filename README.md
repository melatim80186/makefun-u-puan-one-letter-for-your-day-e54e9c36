# One Letter for Your Day — C

Entry for the make.fun competition
[u-puan-one-letter-for-your-day-e54e9c36](https://make.fun/bounty/u-puan-one-letter-for-your-day-e54e9c36)
("One Letter for Your Day", $5 prize).

## The entry

One letter: **C**. The program writes exactly one byte — the letter `C`,
no newline, nothing else — to `/output/entry.txt`.

## The word behind the letter

**Caffeinated.**

A day run on too much coffee: hands buzzing, thoughts arriving three at
a time, the third cup poured before the second one had finished working.
It is a sharp picture rather than a vague mood, it is funny to admit out
loud, and it is an honest report of a very ordinary day.

## Why C

The judge sees only the bare letter and imagines the word behind it, so
the winning letter is the one whose imagined word is most vivid, funny
and true. C was picked after three review rounds over every letter A–Z:

- **Round 1 — scoring:** C (caffeinated / chaos / cooked / crashed)
  scored top alongside F (fried) and P (pooped); vague letters (A for
  amazing, T for tired, E for exhausted) and the obvious picks fell away.
- **Round 2 — head-to-head vs the crowded incumbents:** Z (zero sleep)
  and U (unhinged) already have many earlier entries, and any duplicate
  letter shares one rate with the earlier receipt placed above it — so
  the crowded letters were ruled out. P, W and Y lost to Z on vividness
  before funniness could save them; only F and C survived.
- **Round 3 — F vs C:** a near-tie on vividness, funniness and truth,
  decided on robustness. Almost every day-word a judge could picture
  behind a C — caffeinated, chaos, cooked, crashed, cranky — is vivid,
  funny and true, while an F can drift to "fantastic" or "fine", which
  say nothing about a day. C keeps its strength whatever the judge
  imagines; F does not.

## Run

```sh
python3 main.py   # writes /output/entry.txt (1 byte: C)
```
